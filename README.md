BrightTV – Viewership Analytics Case Study

1. Project Overview

BrightTV Viewership Analytics is a data analytics project focused on understanding subscriber demographics, television viewing behaviour and content consumption patterns.

The purpose of this project is to help BrightTV grow its subscription base by providing data-driven insights and strategic recommendations to the Customer Value Management (CVM) team.

The analysis uses subscriber profile information and viewing transaction records to identify consumption trends, popular channels and opportunities to improve viewer engagement.

2. Business Problem

BrightTV aims to increase its subscription base during the financial year. To achieve this objective, the business needs to understand:

* Who its viewers are.
* What content viewers consume most.
* When viewers are most active.
* Which days experience lower viewing activity.
* What factors influence viewing consumption.
* How to attract new subscribers and retain existing viewers.

3. Project Objectives

The main objectives are to:

1. Analyse subscriber demographics and viewing behaviour.
2. Identify popular channels and consumption trends.
3. Examine viewing patterns across weekdays and different times of the day.
4. Identify factors that may influence content consumption.
5. Recommend content strategies to increase viewing activity on low-consumption days.
6. Develop initiatives to grow BrightTV’s subscriber base.

4. Tools and Technologies

Tool	Purpose

Databricks SQL	Data cleaning, transformation and analysis
Google Data Studio	Data visualisation and dashboard development
Microsoft Power BI	Interactive dashboards and business intelligence

5. Project Workflow

The project followed these stages:

Stage 1: Data Preparation

* Inspected subscriber profile and viewing transaction datasets.
* Reviewed data quality and consistency.
* Prepared the datasets for analysis using Excel.

Stage 2: Data Cleaning and Transformation

* Imported datasets into Databricks.
* Cleaned and transformed subscriber information.
* Combined subscriber profiles with viewing transaction data.
* Converted UTC timestamps to South African time (SAST).
* Calculated viewing duration in minutes and seconds.

Stage 3: Data Analysis

* Analysed viewer demographics.
* Examined channel popularity.
* Investigated viewing activity by day of the week.
* Analysed viewing behaviour by time of day.
* Evaluated total viewing sessions and consumption duration.

Stage 4: Data Visualisation

* Created dashboards and visual reports using Google Data Studio.
* Developed interactive visualisations and KPI cards in Power BI.
* Presented findings to support business decision-making.

7. Key Areas of Analysis

The project explored:

* Viewer demographics by age group and gender.
* Viewing consumption by channel.
* Viewing activity across weekdays.
* Consumption patterns by time of day.
* Total viewing duration and session frequency.
* Differences in viewing behaviour across subscriber groups.

8. Business Recommendations

Based on the analysis, the following strategies can support BrightTV’s growth:

* Introduce targeted content promotions on days with lower viewing activity.
* Recommend personalised content based on subscriber preferences.
* Promote popular channels and programmes to increase engagement.
* Introduce new content categories to attract different audience segments.
* Use viewing patterns to improve content scheduling.
* Develop customer retention campaigns to encourage continued subscriptions.

9. Expected Business Impact

The project aims to help BrightTV:

* Increase viewer engagement.
* Improve content consumption.
* Strengthen customer retention.
* Identify opportunities for subscription growth.
* Make informed, data-driven business decisions.

10. Project Deliverables

* Cleaned and transformed datasets.
* SQL queries developed in Databricks.
* Data analysis and validation.
* Google Data Studio dashboard.
* Microsoft Power BI dashboard.
* Business insights and strategic recommendations.

11. Conclusion

The BrightTV Viewership Analytics project demonstrates how data analytics can transform raw subscriber and viewing transaction data into meaningful business insights.

By combining data preparation, SQL analysis and interactive visualisation, the project provides a foundation for understanding customer behaviour and identifying opportunities to improve engagement and grow BrightTV’s subscription base.
